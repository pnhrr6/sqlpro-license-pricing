## 三个容易被忽略的授权条款

**更新到底含不含**

官网对终身授权的说法是包含该平台所有未来的更新和新功能。这一条对 Studio 是好消息，不少同类工具的大版本升级要另外掏钱。

荔枝的售后政策里还有一条要读。页面上“终身版”“买断制”“永久更新”这些表述，是基于软件开发商上架时提供的说明整理的，开发商可能在未提前通知的情况下调整授权规格，荔枝不保证这些描述和开发商最新政策完全一致。真出了规格变动，责任在开发商，荔枝不承担赔偿或退款。

这段话是国内授权码零售商的标准免责，不是荔枝一家的问题。你把它理解成“承诺的最终解释权不在零售商手里”就行。

**能激活几台机器**

官网 FAQ 只说终身授权限单平台，没写具体能激活几台设备。订阅那边写的是“所有设备上的 iOS 和 Android 应用”，也没给台数上限。荔枝商品页如果标了设备数，以页面为准；没标的，下单前问一句客服。

**买错版本能不能退**

荔枝的售后政策写得很明确，数字商品一经交付，不适用七天无理由退货。

例外情形里有一条和这篇文章直接相关。买错版本，比如用 Mac 却买了 Windows 版，只要已经重新买了正确版本，并且客服联系开发商确认能回收或销毁已交付的激活码，可以退。另外交付时间比订单状态显示的预期晚 2 个工作日以上、订单卡在“处理异常”超过 2 个工作日，也在可退范围内。

激活码一旦发出去就收不回来，所以“先试用再买”是荔枝自己在政策里反复强调的事，并非客套话。试用中遇到问题，政策原话是“请勿购买”。

## 常见问题

**荔枝卖的 SQLPro 是正版吗**

是。荔枝的购买须知里写明，所售商品均为软件官方授权的正版激活码或授权文件，商店只提供安装、注册激活这类基础支持。

**买完发现买错版本了怎么办**

在政策允许的范围内可以退，前提是你已经重新购买了正确版本，并且客服能联系开发商回收已交付的激活码。发现买错第一时间找客服，不要自己反复试激活。

**Mac 版授权能用在 Windows 上吗**

不能。官网的终身授权是单平台的，macOS 和 Windows 分开销售，一份授权只覆盖一个平台。

**以后大版本更新要再付钱吗**

按官网当前的说法，终身授权包含该平台所有未来的更新和新功能。荔枝的免责条款提醒了一句，开发商保留调整授权规格的权利，这一点买之前心里有数。

**学生有优惠吗**

官网写明学生可以免费用一年。具体申请方式去官网看，荔枝这边没有对应的学生档位。
